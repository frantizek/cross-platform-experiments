# Cross-Platform Experiments

A single repository for experimenting with **Node.js**, **Go**, and **Rust**.

## Structure
- `nodejs/`: Node.js project
- `go/`: Go project
- `rust/`: Rust project

## Setup
### Node.js
1. Navigate to `nodejs/`.
2. Run `npm install` (if dependencies exist).
3. Run `node src/app.js`.

### Go
1. Navigate to `go/`.
2. Run `go run src/main.go`.

### Rust
1. Navigate to `rust/`.
2. Run `cargo run`.
